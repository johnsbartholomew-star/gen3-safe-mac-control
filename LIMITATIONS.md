# Alpha limitations

This package reuses existing native Gen3 window, Accessibility action and inspection techniques with standalone validation, receipt and command code. It does not replace the installed private platform.

- Builder and independent reviewer used the same Apple Silicon Mac, macOS 26.6.2, Python 3.14.7 and Swift 6.4.2. The reviewer built a separate clean source copy. No second-host, Intel, older-macOS or non-English compatibility acceptance is claimed.
- The independently tested native behavior is the included Cocoa fixture's one `demo --perform` action, with a separately observed counter change from 0 to 1 and closure of the exact owned fixture. Window raise, activation, Calculator and other applications remain unqualified.
- The 19-test suite and seven additional injected challenge cases are synthetic controls. They do not establish native adversarial behavior for secure/editable fields, ambiguity, changed trees, focus or interrupted effects.
- The reviewer's first native admission was denied in a restricted execution context. A separately authorized command-specific route subsequently had Accessibility access without changing macOS permissions. This does not establish permission inheritance or identify the sole cause of the earlier denial.
- An earlier builder request was denied after a lazy Accessibility group changed the tree. The refusal and original test-fixture failures are preserved. No production guard was weakened and no uncertain result was erased.
- The snapshot fingerprint covers the permitted window traversal. Lazy or changing app trees can produce conservative denials. UI time-of-check/time-of-use remains; a verified postcondition is not an atomic transaction or general guarantee of intent.
- The native helper and same-user local files are trusted. Receipt hashes are not caller authentication or protection against a hostile local user. Static-text observations may contain sensitive information.
- No OS sandbox, hard deadline, resource isolation, complete lock/session security boundary, safety certification or Apple affiliation is claimed.
- No arbitrary typing, coordinate clicks, export, file edits, browser interaction, production media action, remote agent, service, startup item or automatic retry is provided.
- This is an experimental source alpha. The original private Gen3 historical regression counts do not apply to this package.
